# Trade Compass — GASトレードノート

Google Apps ScriptのWebアプリとして動作し、データをGoogleスプレッドシートへ保存する個人向けトレードノートです。

## 主な機能

- 購入記録：日付、銘柄、数量、取得単価、平均取得単価、利確目標、備考
- 売却記録：未決済の購入ロットを選択し、残数量を検証して実現損益を自動計算
- 銘柄記録：複数の購入目標・利確目標、現在値、直近1年の高値・安値、直近の決算情報を取得・保存
- 資産管理：基準日ごとに証券会社別の現金、保有商品評価額、その他資産、負債、純資産を記録・集計し、履歴を基準日・証券会社で並べ替え
- トレード方針：「常に上位」にした鉄のおきてを一覧上位とダッシュボードに固定
- お気に入り：投資理由、注目材料、リスク、目標株価などを保存
- ダッシュボード：実現損益、保有取得額、勝率、取引件数を表示
- スマートフォン対応

## セットアップ

1. Apps Script APIを有効化し、Node.jsを用意します。
2. このフォルダで `npm install` を実行します。
3. `npx clasp login` でGoogleへログインします。
4. 新規作成する場合：`npx clasp create --title "Trade Compass" --type webapp --rootDir ./src`
5. 既存プロジェクトの場合：`.clasp.example.json` を `.clasp.json` にコピーし、Script IDを設定します。
6. `npm run push` で反映します。
7. Apps Script画面から「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。
8. Webアプリを開き、「設定」で保存先スプレッドシートを新規作成または指定します。

## 株価取得について

銘柄コードが4桁の数字なら自動的に `.T` を補い、日本株として検索します（例：`7203` → `7203.T`）。米国株は `AAPL` のようにティッカーを入力します。外部公開データを参照するため、提供元の仕様変更、銘柄、市場、休場状況などにより取得できない場合があります。投資判断の前には証券会社等の公式情報も確認してください。

## データシート

設定時に `Trades`、`Stocks`、`Policies`、`Favorites` の4シートを自動作成します。列名やID列はアプリの整合性維持に使うため、削除・並べ替えは避けてください。

## 今後あると便利な機能

- 手数料・税金を含めた純損益
- 損切り予定、リスクリワード比、最大許容損失

- 月次損益カレンダーと資産推移グラフ
- CSV出力、バックアップ、画像（チャート）の添付
- 配当・信用取引・複数口座への対応
